## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| guardrail-status.json -> report.sh | Untrusted-file parse: halted/haltedAt/haltedRule read by report.sh for the first time. Values must never reach shell or python via string interpolation. |
| haltedAt -> sha1 / ledger key / CLI argv | haltedAt drives the synthetic id and the JOB:halt:<haltedAt> ledger key and may be embedded (rule name) in job_name; must be injection-safe. |
| jobs ledger -> exactly-once gate | The JOB:halt:<haltedAt> line governs reprocessing; a poisoned ledger line could skip or replay a halt. |
| jobs/CLI failure -> halt UX | Fail-open guarantee: a jobs/CLI failure must never break metering, the agent halt message, or clear-halt. |
