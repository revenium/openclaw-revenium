# Phase 15 Plan 01: Combined Enforcement Plugin Summary

One-liner: Combined `revenium-enforcement` plugin with build-time inlined BUDGET-GUARD.md directive, `<revenium-guard>` tag wrapping, and verbatim gate.js marker hooks — plus `_maxAgeSeconds` freshness rule added to BUDGET-GUARD.md.

## What Was Built

A fully-buildable, unit-tested, committed-artifact OpenClaw plugin (`revenium-enforcement`) under `plugin-nemoclaw/` that registers four hooks in one package:

1. **`before_prompt_build`** — injects the BUDGET-GUARD.md directive (baked at build time via `scripts/bake-directive.js`) wrapped in `<revenium-guard>...</revenium-guard>` tags into every agent turn (NCENF-01, D-01/D-02/D-10)
2. **`before_tool_call`** — observes exec/bash tool calls for marker tracking (NCENF-02)
3. **`before_agent_finalize`** — returns bounded revise action when exec ran but write-marker.sh did not (NCENF-02)
4. **`agent_end`** — cleans up per-runId tracking state (NCENF-02)

All hooks are fail-open (CR-01): a throw inside any handler resolves to undefined/no-op, never blocks the turn.

The `BUDGET-GUARD.md` directive was also updated with a `_maxAgeSeconds` freshness rule (D-03/D-04): if the field is present and the status is stale, treat as warned; if absent, skip the check entirely (standalone guardrail-check.sh path is unaffected).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Cross-package tsc relative import fails (TS5055)**
- **Found during:** Task 3
- **Issue:** `import ... from "../../plugin/src/gate.js"` in index.ts causes `error TS5055: Cannot write file 'plugin/src/gate.js' because it would overwrite input file`. tsc follows the relative import outside rootDir and tries to emit there.
- **Fix:** `scripts/bake-directive.js` was updated to also copy `plugin/src/gate.js` into `plugin-nemoclaw/src/gate.js` at build time. index.ts imports from `./gate.js` locally. D-06 is preserved: the single shared source is consumed at build time, not forked — any edit to `plugin/src/gate.js` is picked up on the next rebuild.
- **Files modified:** `plugin-nemoclaw/scripts/bake-directive.js`, `plugin-nemoclaw/src/index.ts`
- **Commit:** 89b2213

**2. [Rule 1 - Bug] `api.log` not in current OpenClaw SDK (TS2339)**
- **Found during:** Task 3
- **Issue:** `api.log?.(msg)` causes `error TS2339: Property 'log' does not exist on type 'OpenClawPluginApi'`. The current openclaw 2026.6.x SDK exposes `api.logger: PluginLogger` (with `.info/.warn/.error/.debug`). The Phase 11 plugin was compiled against an older SDK where `log` existed; its committed dist was never recompiled so the issue was hidden.
- **Fix:** Changed to `api.logger.info(msg)`. Both are functionally equivalent; `api.logger.info` is the correct current API.
- **Files modified:** `plugin-nemoclaw/src/index.ts`
- **Commit:** 89b2213
