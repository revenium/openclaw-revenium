# Quick Task 260604-qo0: Job Outcome Type stuck at "Pending"

## Problem

Agentic jobs reach Revenium and close with the correct execution `--result`
(SUCCESS / FAILED / CANCELLED), but their **business "Outcome Type" column is
always "Pending"**. The Hermes reference plugin
(`hermes-revenium/skills/revenium/scripts/hermes-report.sh:1212-1224`) avoids
this by appending `--outcome-type CONVERTED` to the `jobs outcome` call **only
on SUCCESS arcs** — FAILED/CANCELLED carry no `--outcome-type` so Revenium's
default applies.

Our `scripts/report.sh` deliberately omitted this under decision **D-07**
("execution-result-only"), deferring it to requirement **JOUT-01**. This task
pulls the SUCCESS→CONVERTED slice of JOUT-01 forward to fix the visible bug.
`--result` (execution result) and `--outcome-type` (business outcome) are
distinct axes; we only set the business outcome on success.

## Root Cause

`scripts/report.sh:1077` builds the in-loop outcome command with only
`--result "${job_status}" --quiet` and never passes `--outcome-type`
(comment at line 1068/1078: "D-07: NO --outcome-type ever"). The halt-path
outcomes (lines 1348, 1400) are always CANCELLED and correctly stay untouched.

## Tasks

1. **`scripts/report.sh`** — in the in-loop `jobs outcome` block (~line 1077),
   append `--outcome-type CONVERTED` to `outcome_cmd` when
   `job_status == "SUCCESS"`. Mirror Hermes exactly: SUCCESS only; FAILED and
   CANCELLED unchanged. Update the D-07 comments (lines 1068, 1078) to reflect
   the new SUCCESS→CONVERTED mapping (no longer "never"). Leave the halt-path
   CANCELLED outcomes (1348, 1400) as-is.

2. **`tests/test_report_jobs_argv.sh`** — GROUP A runs J1 SUCCESS + J2 FAILED +
   J3 CANCELLED. Replace the old D-07 assertion (lines ~307-313, "no
   --outcome-type token EVER") with: exactly **1** `--outcome-type` token in
   ARGV_FILE_A, its value is `CONVERTED`, and it co-occurs only with the SUCCESS
   arc (FAILED/CANCELLED emit none). Keep the `--result CANCELLED`/`SUCCESS`
   assertions intact.

3. **Verify** — run `tests/test_report_jobs_argv.sh` (and the broader job/argv
   suite) to confirm GREEN, ensuring the added SUCCESS token breaks no
   count-based assertions elsewhere.

## Out of scope

- `--outcome-value` / `--outcome-currency` / ROI metrics (rest of JOUT-01).
- FAILED/CANCELLED outcome-type mapping (Revenium default is correct).

## Done when

- A successful job shows Outcome Type "Converted" in Revenium (SUCCESS arc emits
  `--outcome-type CONVERTED`); FAILED/CANCELLED arcs still emit no
  `--outcome-type`.
- `tests/test_report_jobs_argv.sh` passes with the updated assertion.
