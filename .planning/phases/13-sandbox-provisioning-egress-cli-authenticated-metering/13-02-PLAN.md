| Boundary | Description |
|----------|-------------|
| operator env → install script | REVENIUM_API_KEY and friends enter as env vars; untrusted-formatting risk on write. |
| host script → sandbox (nemoclaw exec) | Commands cross into the sandbox; payload quoting + process-listing exposure risk. |
| sandbox → GitHub CDN | Tarball download crosses an untrusted CDN boundary. |
| sandbox → api.revenium.ai | Authenticated billable write crosses to the real Revenium API. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-TAR | Tampering | deliver_revenium_cli tarball fetch | mitigate | sha256-verify the downloaded tarball (rev.tgz) against the pinned REVENIUM_CLI_TARBALL_SHA256; exit 2 + fail (abort install) on mismatch (D-02) |
| T-13-KEY | Information Disclosure | REVENIUM_API_KEY handling | mitigate | Write key to /sandbox/.config/revenium/config.yaml via single-quoted heredoc, chmod 600; never place the key on a nemoclaw exec command line (D-05, Pitfall 5) |
| T-13-INJ | Tampering | config.yaml value write | mitigate | Single-quoted heredoc tag (<<'YAML') prevents in-sandbox shell expansion of operator-supplied values (V5) |
| T-13-EGR | Elevation of Privilege | egress preset scope | mitigate | Apply only the two host-scoped shipped presets; host-scoped confirmed in spike 002 (control host stays blocked) |
| T-13-BILL | Spoofing | billable meter probe | mitigate | Ledger key meter-probe-passed makes the probe exactly-once; --task-type install-smoke-test tags the event synthetic for dashboard filtering (D-06) |
| T-13-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs in this phase — only a sha256-pinned GitHub release tarball (covered by T-13-TAR). RESEARCH Package Legitimacy Audit: no packages introduced. |
