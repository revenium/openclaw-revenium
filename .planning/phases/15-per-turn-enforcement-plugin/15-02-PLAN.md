## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-05 | Elevation of Privilege | hand-placed plugin via mount copy | mitigate | A clean `openclaw plugins install` (not the bare copy) records provenance/trust; the inspect gate aborts non-zero if before_prompt_build is not trusted/active (Task 2, D-09) |
| T-15-06 | Tampering | config patch over nemoclaw exec | mitigate | Single-line JSON5 `sh -lc` payload only (nemoclaw exec rejects newline argv); allowConversationAccess scoped to this plugin entry; JSON5 merge is re-run-safe (Task 1) |
| T-15-07 | Denial of Service | install validation hangs/leaks | mitigate | Turn-test reads finalPromptText (prompt-side, deterministic) not a model reply; `2>/dev/null || true` capture avoids exec error propagation; fail-HARD on absence rather than hang-wait (Task 2, D-10) |
| T-15-08 | Information Disclosure | marker write path leaking egress | accept | write-marker.sh writes a LOCAL markers/<sid>.jsonl only — no revenium CLI, no egress, no SSL_CERT at this step (D-07); the host loop meters separately. No secret crosses the boundary here |
| T-15-09 | Spoofing | mount-path integrity for plugin delivery | mitigate | Reuse the Phase 14 mount-establish/self-heal helper; only the SANDBOX_NAME-scoped mount under `${HOME}/sbx-openclaw-${SANDBOX_NAME}` is written; rm -rf the dest before copy to avoid stale-file blends (Task 1, D-11) |
| T-15-SC | Tampering | npm/openclaw plugins install | mitigate | `openclaw plugins install` is the trusted provenance gate, not an npm registry fetch; no new package-manager packages are pulled. Validation gate (Task 2) is the blocking check |
