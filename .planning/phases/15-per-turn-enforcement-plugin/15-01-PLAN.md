## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build host → plugin dist/ | Build-baked directive text becomes runtime-trusted code shipped to the sandbox |
| BUDGET-GUARD.md → guard.js (bake) | Untrusted-looking template-literal injection if escaping is wrong |
| plugin hooks → agent turn | A misbehaving hook could hang or leak (spike 006 hang) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Tampering | bake-directive.js writing guard.js | mitigate | Escape `\\`, backtick, and `${` so BUDGET-GUARD.md content cannot break out of the template literal or inject executable expressions into guard.js (Task 2 escaping rule) |
| T-15-02 | Denial of Service | before_prompt_build hook | mitigate | Pure/static directive constant, zero fs/network/child_process at hook time (D-02); fail-open try/catch returns undefined — closes the spike-006 trusted-but-hung mode at the source (Task 3) |
| T-15-03 | Tampering | empty/omitted configSchema in manifest | mitigate | Ship a valid non-empty `configSchema` object — spike 006 proved a bad manifest breaks the whole openclaw CLI (Task 2 acceptance) |
| T-15-04 | Repudiation | forked marker logic divergence | mitigate | Import safe* wrappers verbatim from shared plugin/src/gate.js; Phase 11 tests guard it — no second copy to drift (D-06, Task 3) |
| T-15-SC | Tampering | npm install (devDeps: typescript, @types/node) | mitigate | No new runtime packages; devDeps mirror the already-audited Phase 11 plugin (typescript, @types/node). No package-manager runtime additions — no install checkpoint required |
</threat_model>
