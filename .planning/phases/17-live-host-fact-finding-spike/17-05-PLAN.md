Run the two remaining live-host questions against one shared window of real agent traffic: SPIKE-02's per-model hook-firing matrix across the six hooks the skill depends on, and SPIKE-04's concurrency soak of the read mechanism SPIKE-01 selected. Both need sustained live traffic on both production pairings, and running them against the same traffic is strictly better than deriving "how do I generate qualifying turns" twice.

Run the soak as **two cells**, each at least **60 consecutive per-minute ticks** while an agent is actively producing turns in that cell:
