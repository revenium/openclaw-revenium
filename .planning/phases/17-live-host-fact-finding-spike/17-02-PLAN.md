<objective>
Return a yes/no verdict, with live evidence, on whether the `command-dispatch: tool` SKILL.md frontmatter field makes marker-writing dispatch deterministic instead of model-judgment-dependent — and do it in the order that does not waste live-host time: the cheap scope check first, the expensive cross-model determinism run only if the scope check earns it.

Purpose: SPIKE-03 is the only phase-17 requirement whose answer changes the shape of the milestone rather than the shape of an implementation. A YES scopes Phase 21 in; a NO moves ATTR-01 to Future Requirements, deletes Phase 21, and ports the existing marker architecture as-is under Phase 20 (D-06). RESEARCH surfaced that the documented scope of `command-dispatch: tool` is slash-command routing — routing the *user's* slash command directly to a tool — and nothing documents it as a per-turn enforcer for an agent-initiated action like marker-writing. That makes "mechanism inapplicable" a live possibility CONTEXT.md did not anticipate, and it is cheap to test. This plan runs it first so a NO on scope does not cost a two-model soak.
Output: `.planning/spikes/010-command-dispatch-tool-verdict/` containing the throwaway probe skill, the raw dispatch log, and the SPIKE-03 determination.
</objective>

Deploy it two ways so both pairings are covered from the start (D-07): to the standalone path's skills directory on the host, and to the sandbox via `nemoclaw revenium-2-0 skill install <path>` (remember: `skill install` does not run `post-install.sh`, so anything the probe needs in-sandbox must be done separately, and `exec` argv must stay single-line because NemoClaw's gRPC rejects newlines).

- **Trigger A — human-typed slash command.** Invoke the skill's slash command as a user message. This is the documented path and is expected to fire; it establishes that the probe skill is wired correctly and that a non-firing Trigger B is a scope finding rather than a broken probe.
- **Trigger B — agent-initiated, mid-turn.** Drive a turn in which the agent itself must invoke the skill's command as part of its own tool-call flow, without a human typing the slash command. This is the call shape marker-writing actually has.

Record each attempt in `dispatch-run.log` with the exact command, the raw trimmed output, the host, the pairing, and the versions in effect (D-12). Close the log with exactly one machine-readable classification line:
- `SCOPE-APPLICABLE` when Trigger B fired the dispatched tool, or
- `SCOPE-NOT-APPLICABLE` when Trigger A fired and Trigger B did not.

Do not write a classification line if Trigger A itself did not fire — that means the probe is broken, not that the mechanism is inapplicable; fix the probe and re-run. Conflating a broken probe with a scope finding is the exact category error RESEARCH warns about.
