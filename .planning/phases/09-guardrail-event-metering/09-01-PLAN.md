<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Revenium API response → meter argv | enforcement-rules JSON (ruleId, rule name) is read from the trusted Revenium API and flows into meter completion argv |
| SESSIONS_DIR → --agent | the newest session file's id is read off disk and resolved to a root session id used for attribution |
| jobs ledger → --agentic-job-id | the jobs ledger (written by report.sh) is read to pick an open job id |
| meter emission ↔ enforcement path | metering must never gain the ability to block enforcement (status write / notifications / cron exit) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01-01 | Tampering | meter argv (rule name/id injection) | mitigate | `cmd+=(--flag "$val")` bash-array discipline, never eval/`${cmd[*]}`; env-passing heredocs (no `${}` inside `<<'PY'`); ruleId/name originate from the trusted Revenium API |
| T-09-01-02 | Tampering | GUARDRAIL_LEDGER_FILE path/write | mitigate | Path is a fixed constant under OPENCLAW_HOME (not derived from input); `touch ... || true`; `grep -qF` fixed-string match; append-only under the cron flock (no separate lock needed) |
| T-09-01-03 | Spoofing/Info disclosure | attribution reading another session's id | accept | Newest-mtime session in the scoped SESSIONS_DIR is the intended root-session heuristic (D-07); basename strips path components; no cross-tenant data — id only labels the agent |
| T-09-01-04 | Denial of Service | metering coerced into blocking enforcement | mitigate | Section M is strictly last (after durable status write + notifications); function returns 0 on all paths; every call wrapped `\|\| true`; a forced meter failure is asserted to keep exit 0 (GRDEV-05) |
| T-09-01-05 | Repudiation | double-emit on concurrent runs | mitigate | cron flock prevents concurrent execution; transition gate is primary; revenium-guardrail.ledger is the secondary exactly-once backstop |
| T-09-01-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase (RESEARCH: "Not applicable") |
</threat_model>
