<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-supplied `failure_reason` prose → --metadata JSON → revenium argv | failure_reason can contain quotes/braces/newlines; it crosses into a CLI JSON arg here |
| agent-supplied `agentic_job_id`/`job_name`/`job_type` → jobs create/outcome argv | sanitized at write time; consumed here as positional/flag values |
| job-CLI exit codes → process_session control flow / offset gate | a job failure must NOT cross into the completion offset gate (double-bill risk) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-08 | Tampering / EoP | `--metadata` JSON breakout via failure_reason prose | mitigate | Build the metadata via env-passing `FR="$failure_reason" python3 ... json.dumps(...)` heredoc (D-08, T-04-09); pass the result as a single bash-array element `--metadata "$outcome_metadata"`. Never string-concat/eval, never `${failure_reason}` inside the program text. |
| T-06-09 | Tampering / EoP | job id / name / type reaching `jobs create`/`outcome` argv | mitigate | Bash arrays only (`cmd+=(--name "$job_name")`, positional `"${job_id}"`); never eval/unquoted. Phase-5 sanitization (`:`/`|`/newline→`_`) is the upstream net. |
| T-06-10 | DoS / Tampering | job-CLI failure wedging the completion offset (re-meter/double-bill) | mitigate | Job calls use OWN exit locals; never touch failed_count/reported_count; stay out of the CR-02 gate (report.sh:693); never return/exit process_session (Pitfall 1/6, D-12). |
| T-06-11 | Repudiation | duplicate create/outcome across cron ticks | mitigate | Ledger-gated (`grep -q "^JOB:<id>:created:/:outcome:"`) + 409-as-success backstop for the crash-between-API-and-ledger window (D-06/D-09). |
| T-06-12 | Tampering | ledger file path handling | mitigate | JOBS_LEDGER_FILE is a fixed config path (env-overridable), not constructed from any marker field; rows are appended with literal prefixes, no interpolation of untrusted values into the path. |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | Phase 6 installs ZERO packages (RESEARCH: Package Legitimacy Audit not applicable). No install tasks. |
