<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent turn → plugin hooks | The plugin observes tool-call events (toolName, params.command) crossing from the harness into plugin code; untrusted tool params are read but never executed |
| plugin → harness revise | The plugin's static `retry.instruction` crosses into the model conversation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-injection | Tampering | before_agent_finalize retry.instruction | mitigate | Instruction is a static plugin-source string; no event/conversation input is interpolated (verified by acceptance criterion) |
| T-11-cmd-read | Tampering / Input Validation | before_tool_call params.command | mitigate | `typeof cmd === "string"` guard before `.includes`; string is only read (`.includes`), never executed or interpolated |
| T-11-state-leak | Information Disclosure | execRuns / markedTaskRuns in-process Sets | mitigate | Per-runId entries cleared in agent_end; not keyed per-user; multi-user gateway cannot accrete cross-session state |
| T-11-fail-open | Denial of Service | before_agent_finalize handler | mitigate | Handler returns undefined on missing runId / errors; SDK top-level catch → continue (verified in RESEARCH); a hook fault never blocks the reply |
</threat_model>
